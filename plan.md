Rotary Fun Quiz system
concept:
-students can be selected by spinning wheel
students can be selected by random selection only in 1 hour of lecture same student mustnot be selected so everyone could get chance.
now before starting the game first we will select teacher, class, subject, lesson, topics, subtopics.
then we will start the game. (there will be time limit for each question of 2 minutes then new spin will be started and student will rotate or spin the wheel to select next student)
- now the data that we are going to select will be stored in database.
- but questions will be from both database and generated parallel questions by ai
- now there will be two roles 1. superadmin 2. admin(teachers)
- login screen will be common for both roles superadmin will be identified if login credential matches (admin@gmail.com, Rotary@123) and teachers will log in with credentials provided by superadmin
- here superadmin will have total control on app from creating teachers, classes, subjects, lessons, topics, subtopics to deleting them and adjusting settings everything like he is a only creator and destroyes even superadmin will observe everything which teacher conducted which game in which class at what time along with student performance who got how much point who is best performer, reward system everything with professional dashboard.
- admin have specific role to conduct games and observe games and students performance and reward them along with adding new question with CRUD operations.
